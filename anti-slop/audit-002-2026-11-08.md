# antislop audit 002 (2026-11-08)

Scope: the UI and copy added for the Publikasi video upload, UKS/M paragraph alignment and the heading letter spacing. The changes are uncommitted in the working trees of uks-fe and cms-uks-fe. Mode 2 (after). Nothing below is fixed yet; pick the numbers to fix.

## Findings

1. **HIGH, R-27 (error state):** the site's video popup has no error state. If an uploaded file is missing or the browser cannot decode it, the player stays blank with no message. Fix: on the video's error event, show "Video tidak bisa diputar." with a link that opens the file. File: `uks-fe/src/features/publikasi/components/PublikasiItems.jsx`.
2. **LOW, C-4 (resilience):** when the browser cannot read an uploaded video, the automatic thumbnail fails silently. The admin only finds out on save ("Video unggahan wajib memiliki thumbnail."). Fix: show a hint under the thumbnail field at that moment. File: `cms-uks-fe/src/features/publikasi/publikasi-file-fields.tsx`.
