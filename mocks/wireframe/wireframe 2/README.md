## 🎨 Karakter Wireframe Murni

- **Pola Titik Blueprint (*Dot-Grid*)**: Latar kanvas teknis dengan grid 24px.
- **Kotak Media Bersilang (*Crossed Placeholder*)**: Semua ilustrasi dan gambar menggunakan kotak bergaris putus-putus dengan silang diagonal `X` dan label dimensi.
- **Bar Kerangka Teks (*Skeleton Lines*)**: Mewakili proporsi teks (`w-100`, `w-75`, `w-50`).
- **Tag Anotasi Spesifikasi**: Penanda peran struktural (`SECTION`, `KOMPONEN`, `STEP`).
- **Mode Toggle**: Mendukung mode *Light Wireframe* dan *Technical Blueprint Dark Emerald*.
